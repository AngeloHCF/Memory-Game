# Memory Game

A web-based memory training application built with **vanilla JavaScript**, HTML, and CSS. This app helps users improve their recall skills by memorizing text snippets and practicing accurate typing with immediate feedback

https://angelohcf.github.io/Memory-Game/

---

## Overview
The Memory Game provides an interactive way to memorize phrases or sentences. Users can:

- Select or create items to memorize.
- Practice typing the item from memory.
- Receive **letter by letter feedback** to track mistakes.
- View a **guess history** to monitor progress.

This tool is ideal for improving memory, focus, and typing accuracy.

---

## Features
- **Add & delete memorization items** stored in `localStorage`.
- **Start/Stop game mode** to test your recall.
- **Real-time feedback** on correct and incorrect letters.
- **History tracking** for previous guesses.
- **Responsive modals** for adding new items and reviewing history.
- Clean, dark-themed interface with accessible styling.
